# Embrix Analytics - Frontend

This is the React + Vite frontend for the Embrix Conversational BI platform. It provides a sleek, glassmorphic conversational interface for users to interact with the Embrix database via natural language.

## Architecture & Features

The frontend connects directly to the FastAPI backend and provides several interactive features split between a left-hand Canvas and a right-hand Chat Panel:
* **Chat Panel**: A messaging interface displaying the conversational stream, natural language responses, AI "thought" durations, and interactive business follow-ups.
* **Canvas Panel**: A strict analytical workspace for displaying generated raw SQL queries, data grids, and dynamic charts.
* **Data Grids**: Renders complex SQL query results into scrollable, formatted tables.
* **SQL Editor & Rerun**: Allows users to view the raw SQL generated by the LangGraph agent, manually edit the syntax, and execute a "Rerun" that pipes the code directly into the Auditor Node.
* **Empty Table Warnings**: Detects empty tables in the database on load and displays a dismissible global dropdown warning to prevent users from querying dead data.

## Getting Started

Ensure you have Node.js 18+ installed.

### 1. Install Dependencies
```bash
npm install
```

### 2. Start the Development Server
```bash
npm run dev
```

*Note: The frontend expects the FastAPI backend to be running concurrently on `http://localhost:8001`.*
